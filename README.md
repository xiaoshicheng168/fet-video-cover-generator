# 英文说 · 视频号封面生成器

为 **Foshan English Talks TMC（英文说）** 打造的一键生成视频号封面的本地网页。
纯静态 HTML + CSS + Canvas，无任何依赖、无需安装，打开即用。

> 本目录位于俱乐部运营库（Obsidian Vault）内，该库为 **WorkBuddy 合作项目** 的一部分。
> 生成器遵循库内既有品牌规范，与 `05_公关与品牌/每日一句地道外贸英语/daily-trade-english` 技能包同源。

## 使用方法

1. 双击打开 `index.html`（推荐用 Chrome / Edge / Safari）。
2. 左侧选择模板 → 填文案 → 选配色 / 上传背景照片 / 上传二维码。
3. 右侧实时预览，点 **「⬇ 一键生成并下载 PNG」** 即可得到 1080 宽高清封面。

若浏览器限制了 `file://` 下载，可启动本地服务后访问：

```bash
cd "网站/视频号封面生成器"
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 尺寸

| 选项 | 尺寸 | 用途 |
|---|---|---|
| 竖版 9:16 | 1080 × 1920 | 视频号竖版视频封面（默认） |
| 信息流 3:4 | 1080 × 1440 | 视频号信息流/主页列表封面 |

## 模板

| 模板 | 用途 | 主要字段 |
|---|---|---|
| 例会预告 | 会议前宣传 | 主题、卖点、日期/时间/地点、嘉宾、报名语 + 二维码 |
| 会议回顾 | 会后复盘宣传 | 主题、金句、3 条亮点、日期地点 |
| 会员风采 | 视频号「会员风采」采访项目 | 姓名、职务/会龄、一句话故事 + 二维码 |
| 每日一句 | 每日一句外贸英语视频封面 | 关键词、金句、翻译、例句、标签 |
| 通用封面 | 自由排版 | 标签、标题、副题、金句 + 二维码 |

## 品牌规范（与库内一致）

- 颜色：深青 `#004165` · 酒红 `#772432` · 金黄 `#F2B544` · 奶油底 `#FFF9EF`
- 元素：FET 金色徽章、左侧青+金饰条、白卡阴影信息区、底部深青品牌条
- 口号：`WHERE ENGLISH MEETS REAL BUSINESS`
- 背景照片建议使用无文字插画或现场照片；顶部自动加奶油渐隐保证文字可读

## 素材建议

- 二维码：`05_公关与品牌/官员上任海报/二维码/`（VPM 二维码 / 小助手二维码）
- 插画：与 `daily-trade-english` 技能包同款无字插画风格：
  `premium flat editorial illustration, playful but professional, light paper texture`，
  色板同上，约束 `no text, no letters, no numbers, no logos, no watermark`
- 现场照片：`05_公关与品牌/宣传资料包/2026/` 各主题宣传包中

## 与 WorkBuddy 协作

- 本页为**自包含静态应用**，可直接 zip 发给任意协作方使用。
- 如需打包成 WorkBuddy 技能包，目录结构参考
  `05_公关与品牌/每日一句地道外贸英语/daily-trade-english/`：
  `SKILL.md`（frontmatter 描述）+ `agents/openai.yaml`（interface 定义）+ 本目录文件。
- 文案批量生产仍由既有技能包负责，本工具只做「文字 → 封面 PNG」的最后一公里。
